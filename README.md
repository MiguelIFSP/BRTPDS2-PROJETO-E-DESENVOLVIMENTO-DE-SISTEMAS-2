# BRTPDS2 - PROJETO DE DESENVOLVIMENTO DE SISTEMAS 2
---

# 📊 Sistema de Gerenciamento de Reuniões (MMS)

Um aplicativo *mobile-first*, *open-source* e de *zero-cost* focado em estruturar o ciclo completo de reuniões corporativas (preparar, discutir, registrar e acompanhar), desenvolvido para a disciplina de Projeto e Desenvolvimento de Sistemas II.

---

### 🚀 Visão Geral
No cenário atual, ferramentas tradicionais de reuniões são pesadas, focadas em desktop e frequentemente escondem funções essenciais atrás de assinaturas pagas. 

Nosso projeto propõe uma alternativa moderna e independente: um aplicativo móvel simples e intuitivo, operado sobre uma infraestrutura local (Self-Hosted). O sistema garante total privacidade dos dados da empresa sem a burocracia de cadastros em nuvem, permitindo que times gerenciem pautas, registrem decisões e acompanhem tarefas (Action Items) sem custos de licenciamento.

---

### 💻 Stack Tecnológica

O sistema foi arquitetado para garantir facilidade de uso na ponta do cliente e custo zero de infraestrutura:

**Frontend (Mobile):**
*   React Native + Expo
*   Zustand (Gerenciamento de Estado)

**Backend & Dados:**
*   Node.js + Express (API REST)
*   Prisma ORM
*   MySQL

**Infraestrutura (Self-Hosted):**
*   Docker & Docker Compose (Containerização)
*   Java (Painel Lançador Multiplataforma para simplificação da implantação)
